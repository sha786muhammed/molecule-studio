# Free demo implementation plan

Goal: shorten the GitHub introduction and prepare a no-cost, working frontend and Python calculation backend for Shah to open on his phone.

Architecture: one Docker web service on Render's explicitly selected free plan. FastAPI serves the built React interface and calculations on the same origin. The hosted demo gives each browser a signed, temporary workspace cookie and separate SQLite file. Local launch behavior remains unchanged.

Alternatives considered: static hosting cannot run this Python engine; Hugging Face currently requires a subscription for new CPU Docker Spaces. Render permits a free Docker web service, with sleep and ephemeral storage. This is an implementation choice for the user's existing zero-budget requirement.
